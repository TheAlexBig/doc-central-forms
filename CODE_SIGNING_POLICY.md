# Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

El código de este repositorio se incorpora al MSI producido por
`TheAlexBig/doc-central-app`. `TheAlexBig` desempeña los roles de committer,
revisor y aprobador de firma. Cada solicitud de firma requiere aprobación
manual y debe proceder del workflow público ejecutado en un runner alojado por
GitHub.

La política completa se encuentra en:

<https://github.com/TheAlexBig/doc-central-app/blob/master/CODE_SIGNING_POLICY.md>
